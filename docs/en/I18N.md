# Localization (RU / EN / ES)

The interface and the lessons are available in three languages. Russian is the source
language of the content; English and Spanish are translations laid over it.

## Interface

- `src/i18n/index.js` — locale selection (`pianoL.locale.v1` in localStorage), the `t()` and `tList()` helpers.
- `src/i18n/ru.js`, `src/i18n/en.js`, `src/i18n/es.js` — interface dictionaries sharing the same set of keys.
- A missing key falls back to the Russian dictionary, so an incomplete translation never breaks the interface.

## Note names

`src/constants/piano.js` keeps the note names for every locale:

- ru: До, Ре, Ми, Фа, Соль, Ля, Си
- en: C, D, E, F, G, A, B
- es: Do, Re, Mi, Fa, Sol, La, Si

`noteLabel(midi)` returns the name without the octave, `noteName(midi)` adds the octave number (до₄ = C4).

## Lessons

The structure of a lesson (notes, practice types, staff, number of rounds) is declared once
in the Russian files `src/constants/lessons/*.js`. Translations live separately:

```
src/constants/lessons/i18n/en/<module>.js   → export const <MODULE>_EN = { ... }
src/constants/lessons/i18n/es/<module>.js   → export const <MODULE>_ES = { ... }
src/constants/lessons/i18n/en/index.js      → EN_LESSONS bundle
src/constants/lessons/i18n/es/index.js      → ES_LESSONS bundle
```

`localizeLesson(lesson, locale)` from `src/constants/lessons/localize.js` applies a translation
to the lesson structure. When no translation exists, the Russian text stays.

### Translation pack format

The top-level key is the lesson `id`. The order and the number of blocks must match
the Russian file: the translation is applied by index.

```js
export const BASICS_EN = {
  "keyboard-tour": {
    title: "Meet the keyboard",
    summary: "How white and black keys are arranged.",
    blocks: [
      "first block, type: text → a string",
      ["block of type: list or ordered", "→ an array of the same length"],
      "block type: note → a string",
      { caption: "block type: staff → caption only" },
      { text: "block type: listen", labels: ["button label 1", "button label 2"] },
    ],
    practices: {
      explore: {
        title: "Practice: explore the keyboard",
        instruction: "Play eight different keys.",
        doneText: "Done.",
      },
    },
  },
};
```

Rules:

- `blocks` — exactly as many items as in the Russian lesson, in the same order.
  A block with no text has nothing to translate — use `null`.
- `practices` — keys match the practice `id`s of the Russian lesson.
  Translatable fields: `title`, `instruction`, `doneText`, `startHint`, `chordNames` (array).
- Nothing structural (`notes`, `beats`, `midi`, `type`, `count`, `intervals`) belongs in a pack.
- Key labels (`labels`) are translated automatically: note names are recomputed from midi,
  finger numbers stay as they are.

### Glossary

| Русский | English | Español |
| --- | --- | --- |
| до мажор | C major | do mayor |
| ля минор | A minor | la menor |
| гамма | scale | escala |
| аккорд, трезвучие | chord, triad | acorde, tríada |
| доля, щелчок метронома | beat, metronome click | tiempo, clic del metrónomo |
| такт, размер 4/4 | bar, 4/4 time | compás, compás de 4/4 |
| скрипичный ключ | treble clef | clave de sol |
| басовый ключ | bass clef | clave de fa |
| целая, половинная, четвертная, восьмая | whole, half, quarter, eighth note | redonda, blanca, negra, corchea |
| пауза | rest | silencio |
| тон, полутон | whole step, half step | tono, semitono |
| диез, бемоль | sharp, flat | sostenido, bemol |
| аппликатура, палец 1 | fingering, finger 1 | digitación, dedo 1 |
| уд/мин | BPM | ppm |
| подсветка клавиш | key highlighting | resaltado de teclas |
| круг (повтор задания) | round | ronda |

Addressing the learner: English uses “you”; Spanish uses the informal “tú” with imperatives
(`toca`, `busca`, `escucha`).

## Checks

`npm test` runs `scripts/test-i18n.mjs`, which verifies that the three interface dictionaries
have identical key sets and that all 32 lessons are translated into `en` and `es`
with a matching structure.
