# Дорожная карта (ROADMAP)

> **Внимание:** этот документ описывает **желаемую и планируемую учебную
> программу** (curriculum) — то, к чему проект стремится. Это **не** список
> уже реализованных функций. На текущий момент приложение реализует лишь
> малую часть перечисленного (см. [README.md](./README.md), раздел
> «Ограничения»). Пункты ниже — план развития, а не заявление о готовности.

14. Скрипичный ключ
15. Чтение нот правой рукой
16. Басовый ключ
17. Чтение нот левой рукой
18. Простые мелодии по нотам
19. Гамма До мажор — правая рука
20. Гамма До мажор — левая рука
21. Гамма До мажор — две руки

34. Последовательность I–IV–V–I

## Статус

В текущем прототипе есть упражнение с гаммой До мажор в одну октаву
с выбором руки; это основа для тем 19–20, а не полный курс.
Этот список описывает целевую программу и не является перечнем готовых уроков.
Возможности прототипа описаны в [README.md](./README.md).
