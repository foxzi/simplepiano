# Мультиязычность (RU / EN / ES)

Интерфейс и уроки доступны на трёх языках. Русский — исходный язык контента,
английский и испанский накладываются поверх него переводами.

## Интерфейс

- `src/i18n/index.js` — выбор локали (`pianoL.locale.v1` в localStorage), функции `t()` и `tList()`.
- `src/i18n/ru.js`, `src/i18n/en.js`, `src/i18n/es.js` — словари интерфейса с одинаковым набором ключей.
- Недостающий ключ берётся из русского словаря, поэтому интерфейс не ломается при неполном переводе.

## Названия нот

`src/constants/piano.js` хранит названия для всех локалей:

- ru: До, Ре, Ми, Фа, Соль, Ля, Си
- en: C, D, E, F, G, A, B
- es: Do, Re, Mi, Fa, Sol, La, Si

`noteLabel(midi)` даёт название без октавы, `noteName(midi)` — с номером октавы (до₄ = C4).

## Уроки

Структура урока (ноты, типы практик, нотный стан, число повторов) описана один раз
в русских файлах `src/constants/lessons/*.js`. Переводы лежат отдельно:

```
src/constants/lessons/i18n/en/<module>.js   → export const <MODULE>_EN = { ... }
src/constants/lessons/i18n/es/<module>.js   → export const <MODULE>_ES = { ... }
src/constants/lessons/i18n/en/index.js      → сборка EN_LESSONS
src/constants/lessons/i18n/es/index.js      → сборка ES_LESSONS
```

`localizeLesson(lesson, locale)` из `src/constants/lessons/localize.js` накладывает перевод
на структуру урока. Если перевода нет, остаётся русский текст.

### Формат пакета перевода

Ключ верхнего уровня — `id` урока. Порядок и количество блоков обязаны совпадать
с русским файлом: перевод накладывается по индексу.

```js
export const BASICS_EN = {
  "keyboard-tour": {
    title: "Meet the keyboard",
    summary: "How white and black keys are arranged.",
    blocks: [
      "Первый блок type: text → строка",
      ["Блок type: list или ordered", "→ массив строк той же длины"],
      "Блок type: note → строка",
      { caption: "Блок type: staff → только подпись" },
      { text: "Блок type: listen", labels: ["подпись кнопки 1", "подпись кнопки 2"] },
    ],
    practices: {
      explore: {
        title: "Practice: explore the keyboard",
        instruction: "Play eight different keys.",
        doneText: "Done.",
      },
    },
  },
};
```

Правила:

- `blocks` — ровно столько элементов, сколько в русском уроке, в том же порядке.
  Блок без текста переводить нечем — ставится `null`.
- `practices` — ключи совпадают с `id` практик русского урока.
  Переводимые поля: `title`, `instruction`, `doneText`, `startHint`, `chordNames` (массив).
- Ничего структурного (`notes`, `beats`, `midi`, `type`, `count`, `intervals`) в пакете нет.
- Подписи клавиш (`labels`) переводятся автоматически: названия нот пересчитываются из midi,
  номера пальцев остаются как есть.

### Словарь терминов

| Русский | English | Español |
| --- | --- | --- |
| до мажор | C major | do mayor |
| ля минор | A minor | la menor |
| гамма | scale | escala |
| аккорд, трезвучие | chord, triad | acorde, tríada |
| доля, щелчок метронома | beat, metronome click | tiempo, clic del metrónomo |
| такт, размер 4/4 | bar, 4/4 time | compás, compás de 4/4 |
| скрипичный ключ | treble clef | clave de sol |
| басовый ключ | bass clef | clave de fa |
| целая, половинная, четвертная, восьмая | whole, half, quarter, eighth note | redonda, blanca, negra, corchea |
| пауза | rest | silencio |
| тон, полутон | whole step, half step | tono, semitono |
| диез, бемоль | sharp, flat | sostenido, bemol |
| аппликатура, палец 1 | fingering, finger 1 | digitación, dedo 1 |
| уд/мин | BPM | ppm |
| подсветка клавиш | key highlighting | resaltado de teclas |
| круг (повтор задания) | round | ronda |

Обращение к ученику: в английском — «you», в испанском — на «tú» с повелительным
наклонением (`toca`, `busca`, `escucha`).

## Проверки

`npm test` запускает `scripts/test-i18n.mjs`: он сверяет, что три словаря интерфейса
имеют одинаковый набор ключей и что все 32 урока переведены на `en` и `es`
с совпадающей структурой.
