# Учебная тетрадь «Пианино» — документация (русский)

Небольшое веб-приложение для изучения основ теории фортепиано и практики
гаммы до мажор, с опциональной поддержкой MIDI-клавиатуры. Не требует
установки зависимостей на стороне пользователя. Построено на Vue 3 и Vite,
с тремя переключаемыми темами оформления (светлая, тёмная, тетрадь).

## Запуск приложения

Приложение — это проект на Vue 3 + Vite (`src/`, `index.html`,
`vite.config.js`). Все зависимости устанавливаются и запускаются внутри
Docker — `npm install` на хосте не требуется.

Сервер для разработки (с горячей перезагрузкой):

```bash
cd /home/piligrim/Work/audio/piano-l
docker compose up -d
```

Эта команда собирает образ на основе `node:22-alpine`, устанавливает
зависимости внутри контейнера и запускает dev-сервер Vite, доступный на
`127.0.0.1:5174` на хосте (проброшен на порт `5173` внутри контейнера).
Откройте `http://127.0.0.1:5174/` в браузере. Остановить контейнер:
`docker compose down`.

Продакшн-сборка (результат попадает в `dist/`):

```bash
docker compose run --rm app npm run build
```

Dev-сервер привязан только к `127.0.0.1` на хосте — из соображений
безопасности. Если порт 5174 уже занят другим проектом на вашей машине,
измените порт хоста в `compose.yaml` (секция `ports:`).

## Web MIDI: HTTPS/localhost и ограничения браузеров

Web MIDI API (`navigator.requestMIDIAccess`) доступен только в
**безопасном контексте**. На практике это означает одно из:

- страница раздаётся по `https://`, либо
- страница раздаётся по `http://localhost` / `http://127.0.0.1`.

Раздача по обычному `http://` на IP-адресе локальной сети (например,
`http://192.168.x.x`) **не сработает** — браузер не предоставит
`navigator.requestMIDIAccess`, либо метод будет заблокирован при вызове.
Dev-сервер Vite, запущенный через `docker compose up -d`, доступен по адресу
`http://127.0.0.1:5174` — это удовлетворяет требованию безопасного
контекста, поэтому HTTPS-сертификат для локального тестирования не нужен.

Поддержка в браузерах также различается:

- Chrome, Edge, Opera и другие браузеры на Chromium поддерживают Web MIDI.
- У Firefox и Safari исторически была ограниченная поддержка или её не было
  вовсе (проверьте актуальное состояние для конкретной версии браузера,
  прежде чем полагаться на поддержку).
- Приложение определяет оба случая (API отсутствует или небезопасный
  контекст) и отключает кнопку «Подключить MIDI» с поясняющим сообщением
  вместо тихого падения.

Приложение запрашивает доступ к MIDI **без** SysEx (`{ sysex: false }`), это
упрощает запрос разрешения и полностью достаточно для сообщений
note on/off.

## Темы оформления

В переключателе тем в шапке доступны три доступные (accessible) темы:
светлая, тёмная и «тетрадь» (тёплый, похожий на бумагу вид). Выбранная тема
сохраняется в `localStorage` и восстанавливается при следующем визите;
нужная тема применяется до первой отрисовки, чтобы избежать мигания
неверной темой. Если сохранённого предпочтения ещё нет, приложение
опирается на системную настройку `prefers-color-scheme` браузера.

## Проверка на физическом MIDI-оборудовании не проводилась

Приложение было реализовано и проверено продакшн-сборкой
(`docker compose run --rm app npm run build`) в среде без подключённой
физической MIDI-клавиатуры. Код работы с MIDI (`requestMIDIAccess`, выбор
входа, `onmidimessage`, `onstatechange`) следует стандартному контракту Web
MIDI API, но **не проходил** сквозное тестирование на реальном
оборудовании. Перед тем как полагаться на эту функцию, проверьте её с
реальной MIDI-клавиатурой/синтезатором и сообщите об особенностях
конкретных устройств (например, running status, нестандартная разбивка
сообщений), если они встретятся.

Клавиатура на экране и все функции, не связанные с MIDI (синтезатор на Web
Audio, логика упражнения, метроном, уроки теории, сохранение в
localStorage), не зависят от оборудования и были опробованы в браузере в
процессе разработки.

## Упражнение: гамма до мажор, одна октава

- Ноты (номера MIDI): до4=60, ре4=62, ми4=64, фа4=65, соль4=67, ля4=69,
  си4=71, до5=72 — восходящая гамма до мажор в пределах одной октавы.
- Приложение ждёт правильную следующую ноту, прежде чем продвинуться дальше;
  неверные ноты засчитываются как ошибки, но не блокируют прогресс.
- MIDI-сообщение «note on» с velocity, равным 0, согласно спецификации MIDI
  трактуется как «note off», поэтому оно не продвигает упражнение.
- Перед началом можно выбрать аппликатуру для правой или левой руки
  (отображается для каждой ноты).
- Прогресс, количество ошибок и результат прохождения сохраняются в
  `localStorage` (обёрнуто в try/catch — если хранилище недоступно, например
  в режиме инкогнито, приложение аккуратно продолжает работу и сообщает,
  что результат не сохранён).
- Запись о прохождении сохраняется только после того, как все 8 нот
  реально сыграны верно по порядку — никакого «фиктивного» успеха нет.

## Ограничения

- Упражнение охватывает только одну конкретную гамму (до мажор, одна
  октава, восходящее движение). Это отправная точка, а не полный курс.
- Звук синтезатора — простой тон на осцилляторе, а не сэмплированное
  фортепиано.
- Переключатель звука Web Audio влияет только на ноты, приходящие с
  подключённого MIDI-устройства (чтобы не дублировать звук, если у
  оборудования есть собственный синтезатор). Клики по клавиатуре на экране и
  демонстрация гаммы всегда воспроизводят звук после действия пользователя —
  так требуют политики автовоспроизведения браузеров.
- Нет бэкенда, аккаунтов и аналитики — всё работает в вашем браузере.

## Если MIDI-клавиатура не звучит

1. Убедитесь, что в разделе «Клавиатура на экране» включён переключатель
   «Звук синтезатора для MIDI» — по умолчанию он выключен, чтобы не дублировать
   собственный звук инструмента.
2. Если у самого инструмента нет встроенного синтезатора (обычные MIDI-контроллеры
   без звука), этот переключатель обязателен.
3. Проверьте, что в статусе подключения указано имя вашего устройства; при
   подсветке клавиш на экране MIDI-сигнал принимается корректно.
4. Проверьте системную громкость и то, что вкладка браузера не заглушена.
